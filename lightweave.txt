Welcome to Lightweave, a system designed for mechatronic cosplay

Lightweave is structured as follows:
- main.py runs the main loop
- mesh.py provides the espnow mesh network for devices to communicate
- servo.py provides a basic servo driver
- led_controller.py provides a basic led driver
- ssd1322.py provides a basic display driver
- config.json (or <device>.json) provides a configuration that can be adjusted per device


Config structure:

The optional LED `type` is `WS2812` by default; use `SK6812` for RGBW strips.
RGB colors leave the SK6812 white channel off, and a fourth color component can
set it. Define digital output pins in `device.outputs`; preset output states
accept `high` or `low`, with optional `delay` values in seconds.

    "default_preset": "off_preset",
    "debug": true,

      "primary": [120, 50, 0],

      "tertiary": [12, 10, 6],
      "variance": 0.2,

    "background": [

        "module": "bg_script",
        "params": {
          "param1": 10,
          "param2": 20
        }
      }
    ],
    
    "servos": [],
    
    "leds": [
      {"id": "strip1", "pin": 0, "count": 6, "type": "WS2812"},
      {"id": "strip2", "pin": 5, "count": 2, "type": "SK6812"}
    ],

    "outputs": [
      {"id": "amp_enable", "pin": 21, "initial": "low"}
    ],
    
    "buttons": [

        "pin": 20,
